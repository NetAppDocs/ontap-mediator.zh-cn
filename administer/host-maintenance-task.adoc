= 维护 ONTAP Mediator 的主机操作系统
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
确保 ONTAP Mediator 的主机操作系统定期维护，以实现最佳性能。



[[reboot-the-host]]
== 重新启动主机

仅在集群运行状况良好时重新启动主机。ONTAP Mediator 脱机时，集群无法响应故障。在重新启动之前设置维护时间。

ONTAP Mediator 在重新启动期间自动恢复，并重新进入先前配置的与 ONTAP 集群的关系。



[[host-package-updates]]
== 主机包更新

更新除内核之外的任何库或 yum 软件包。如果需要使更改生效，请重新启动主机。在重新启动主机之前，请安排一个服务窗口。

如果安装 `yum-utils`软件包，请使用 `needs-restarting`命令检测是否有任何软件包更改需要重新启动。

更新 ONTAP Mediator 依赖项后重新启动，因为更改不会立即生效。



[[upgrade-the-host-os-kernel]]
== 升级主机 OS 内核

必须为您正在使用的内核编译 SCST。要更新操作系统，您需要安排维护时间。

.开始之前
使用 ONTAP Mediator 安装 SCST 包时，适用以下要求。

* 您可以更新除内核之外的所有库包，但可能需要重新启动才能在 ONTAP Mediator 中应用更改。如果需要重新启动，请安排停机时间。
* 您应该使操作系统内核保持最新。请将内核核心升级到 link:../release-notes/support-matrix.html#scst-support-matrix["ONTAP Mediator 版本矩阵"] 中列出的受支持版本。您必须重新启动系统，因此请为停机规划维护时段。
+
** 请在重新启动之前卸载 SCST 内核模块，然后重新安装。
** 在开始内核操作系统升级之前，请准备好要重新安装的受支持的 SCST 版本。





NOTE: 如果您安装了仅支持 HTTPS 的 ONTAP Mediator 1.12 或更高版本，则不会安装 SCST 包，并且可以升级主机操作系统内核，而不会影响 ONTAP Mediator。有关升级说明，请参阅主机操作系统文档。

.步骤
按照以下步骤升级主机操作系统内核。


NOTE: 在升级内核之前，请检查操作系统和 ONTAP Mediator 版本是否兼容。有关受支持的版本，请参见link:../release-notes/support-matrix.html#os-support-matrix["操作系统支持矩阵"]。

. 停止 ONTAP Mediator。
. 卸载 SCST 包，请参见<<执行主机维护>>。（SCST 不提供升级机制。）
. 升级操作系统，然后重新启动。
. 重新安装 SCST 软件包。
. 重新启用 ONTAP Mediator。




[[perform-host-maintenance]]
== 执行主机维护

升级 VM 内核可能会导致与 SCST 模块的兼容性问题。手动卸载并重新安装 SCST。


NOTE: 如果您安装了仅支持 HTTPS 的 ONTAP Mediator 1.12 或更高版本，则未安装 SCST 包，您可以跳过此任务。

[[step-2-install-scst]]
=== 步骤 2：安装 SCST

要手动安装 SCST，您需要用于已安装版本的 ONTAP Mediator 的 SCST tar 捆绑包（请参阅 <<scst-bundle-table,SCST 表>>）。

.关于此任务
* 在安装 ONTAP Mediator 之前，请执行此步骤。如果您使用的 SCST 版本高于 ONTAP Mediator 安装程序捆绑的版本，则安装程序将跳过此步骤。
* 在某些情况下，由于升级后的操作系统需要修补程序，因此在升级后的操作系统上默认安装 SCST 可能会失败。
+
从 ONTAP Mediator 1.12.1 开始，如果安装失败，您可以使用位于 `/usr/local/bin/mediator_repair_scst`的 SCST 修复工具来修复安装。

+
如果升级后的操作系统需要修补程序，则该工具将包含在 ONTAP Mediator 软件包中附带的 SCST 版本中。该 `mediator_repair_scst`工具是一个独立的工具，与主安装程序分开，并打包在 ONTAP Mediator `tgz`文件中。它不会影响 ONTAP Mediator 的安装或升级路径。



.步骤
. 在 `scst` 目录中运行以下 install 命令：
+
.. `make 2release`
.. `make scst_install`
.. `make usr_install`
.. `make iscsi_install`
.. `make scstadm_install`
.. `depmod`
+
[NOTE]
====
如果您要执行首次安装并希望预安装 ONTAP Mediator，请在继续执行下一步之前运行以下命令：

`mkdir -p /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys`

====
.. `cp scst/src/certs/scst_module_key.der /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/`
.. `patch /etc/init.d/scst < /opt/netapp/lib/ontap_mediator/systemd/scst.patch`
+

NOTE: 如果在首次安装期间在 ONTAP Mediator 之前预安装 SCST，请跳过此步骤。安装程序将应用相关的 SCST 修补程序。



. （可选）如果启用了安全启动，请在重新启动之前执行以下步骤：
+
.. 确定  `scst_vdisk`、 `scst` 和  `iscsi_scst` 模块的每个文件名：
+
....
[root@localhost ~]# modinfo -n scst_vdisk
[root@localhost ~]# modinfo -n scst
[root@localhost ~]# modinfo -n iscsi_scst
....
.. 确定内核版本：
+
....
[root@localhost ~]# uname -r
....
.. 使用内核对每个模块文件进行签名：
+
....
[root@localhost ~]# /usr/src/kernels/<KERNEL-RELEASE>/scripts/sign-file \sha256 \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.priv \
/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der \
_module-filename_
....
.. 使用固件安装 UEFI 密钥。
+
安装 UEFI 密钥的说明位于：

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/README.module-signing`

+
生成的 UEFI 密钥位于：

+
`/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der`



. 重新启动系统：
+
`reboot`





[[host-changes-to-the-hostname-or-ip]]
== 主机更改主机名或 IP

.关于此任务
* 在已安装 ONTAP Mediator 的 Linux 主机上执行此任务。
* 仅在安装 ONTAP Mediator 后，主机名或 IP 地址发生变化，因此自签名证书不再有效时才执行此操作。
* 将临时自签名证书替换为受信任的第三方证书后，请不要使用此任务重新生成证书。如果没有自签名证书，则无法使用此过程。


.步骤
为当前主机创建临时自签名证书：

. 重新启动 ONTAP Mediator：
+
`./make_self_signed_certs.sh overwrite`
