= 重新生成 ONTAP Mediator 主机的临时自签名证书
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当主机名或 IP 地址更改使现有证书无效时，为当前主机重新生成临时自签名证书。


NOTE: 此过程仅在运行 ONTAP Mediator 1.7 或更高版本的系统上受支持。

.关于此任务
* 在已安装 ONTAP Mediator 的 Linux 主机上执行此任务。
* 只有在安装 ONTAP Mediator 后，由于主机的主机名或 IP 地址发生更改而导致生成的自签名证书过时，您才能执行此任务。
* 临时自签名证书被受信任的第三方证书替换后，请不要使用此任务重新生成证书。缺少自签名证书将导致此过程失败。


.步骤
要为当前主机重新生成新的临时自签名证书，请执行以下步骤：

. 重新启动 ONTAP Mediator：
+
`./make_self_signed_certs.sh overwrite`
