= 升级主机操作系统并重新安装或升级 ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要将安装了 SCST 的 ONTAP Mediator 的主机操作系统升级到更高版本，您必须卸载 ONTAP Mediator。操作系统升级后，您可以重新安装当前版本的 ONTAP Mediator 或升级到较新版本。

.关于此任务
* 此任务适用于安装了 SCST 的 ONTAP Mediator 版本。如果您安装了仅支持 HTTPS 的 ONTAP Mediator 1.12 或更高版本，则未安装 SCST 软件包，您可以升级主机操作系统而不会影响 ONTAP Mediator。有关操作系统升级说明，请参阅主机操作系统供应商的文档。
* 如果您只需要将主机操作系统内核更新为受支持的版本，而无需升级到新的操作系统版本，请改为参阅 link:host-maintenance-task.html["维护 ONTAP Mediator 的主机操作系统"]。
* 在使用 leapp-upgrade 工具升级 ONTAP Mediator 的主机操作系统之前，link:uninstall-mediator-task.html["卸载 ONTAP Mediator"]。该工具会检查已注册存储库中的新 RPM 版本。
* ONTAP Mediator 安装程序会安装 .rpm 文件，leapp-upgrade 工具会将其包含在搜索中。由于安装程序解压缩文件而不是从注册存储库下载文件，因此该工具无法找到升级。您必须使用 leapp-upgrade 工具来卸载此软件包。


.步骤
. 备份日志文件：
+
....
[rootmediator-host ~]# tar -czf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator ./log ./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]# tar -tf ontap_mediator_file_backup.tgz
./log/
./log/ontap_mediator.log
./log/scstadmin.log
./log/ontap_mediator_stdout.log
./log/ontap_mediator_requests.log
./log/install_20230419134611.log
./log/scst.log
./log/ontap_mediator_syslog.log
./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]#
....
. 使用 leapp-upgrade 工具执行升级：
+
....
[rootmediator-host ~]# leapp preupgrade --target 9.8
  ..<snip upgrade checks>..
  ..<fix issues found>..
[rootmediator-host ~]# leapp upgrade --target 9.8
  ..<snip upgrade>..
[rootmediator-host ~]# cat /etc/os-release | head -2
NAME="Red Hat Enterprise Linux"
VERSION="8.4 (Ootpa)"
[rootmediator-host ~]#
....
. 重新安装 ONTAP Mediator：
+

NOTE: 重新安装 ONTAP Mediator 后立即执行其余步骤，以防止日志文件丢失。

+
....
[rootmediator-host ~]# ontap-mediator-1.12.1/ontap-mediator-1.12.1

ONTAP Mediator: Self Extracting Installer

  ..<snip installation>..
[rootmediator-host ~]#
....
. 停止 ontap_mediator：
+
....
[rootmediator-host ~]# systemctl stop ontap_mediator
[rootmediator-host ~]#
....
. 替换日志文件：
+
....
[rootmediator-host ~]# tar -xf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator
[rootmediator-host ~]#
....
. 启动 ontap_mediator：
+
....
[rootmediator-host ~]# systemctl start ontap_mediator
[rootmediator-host ~]#
....
. 将所有 ONTAP 集群重新连接到升级后的 ONTAP 调解器：
