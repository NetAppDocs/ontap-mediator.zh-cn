= 升级 ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要将 ONTAP Mediator 升级到较新版本而不升级主机操作系统，请下载新版本的安装包，并在已安装 ONTAP Mediator 的主机上运行安装程序。


NOTE: 如果您需要将主机操作系统升级到新版本，并作为该过程的一部分重新安装或升级 ONTAP Mediator，请改为参见 link:upgrade-host-os-mediator-task.html["升级主机操作系统和 ONTAP Mediator"]。

.开始之前
* 确认您的主机满足link:../install/prepare-install.html["准备安装 ONTAP Mediator"]中所述的先决条件，包括主机、防火墙和操作系统要求。
* 下载新版本的安装软件包。请参阅 link:../install/download-install-pkg-task.html["下载 ONTAP Mediator 安装包"]。
* NetApp 建议验证新安装包的代码签名。请参阅 link:../install/verify-code-signature-task.html["验证 ONTAP Mediator 安装包的代码签名"]。


.关于此任务
在升级 ONTAP Mediator 之前，请查看下列信息。

* 您应该将 ONTAP Mediator 升级到最新版本。旧版本仍然适用于所有 ONTAP 版本，但新版本包含第三方组件的安全补丁。
* 当您升级到包含 SCST 包的新 ONTAP Mediator 版本时，安装程序会自动升级到推荐的 SCST 版本，除非有更高版本可用。有关手动安装更高 SCST 版本的说明，请参见 link:host-maintenance-task.html["维护 ONTAP Mediator 的主机操作系统"]。有关支持的版本，请参见 link:../release-notes/support-matrix.html#scst-support-matrix["SCST 支持矩阵"]。


[NOTE]
====
* 如果升级失败，您可能需要尝试更新版本的 ONTAP Mediator。
* 从 2025 年 6 月 15 日起，您无法安装或升级 ONTAP Mediator 1.9 和 1.8，因为它们的代码签名证书已过期。如果升级失败，请改用 ONTAP Mediator 1.9.1 补丁版本。


====
* 从 ONTAP 9.19.1 和 ONTAP Mediator 1.12 开始，您可以选择安装支持 iSCSI 和 HTTPS 的 ONTAP Mediator，或仅支持 HTTPS。如果您选择安装仅支持 HTTPS 的 ONTAP Mediator，则不会安装 SCST 软件包。
* 如果您从安装了 SCST 的 ONTAP Mediator 1.11 或更早版本升级，并且在升级期间选择了 HTTPS only 选项，则会卸载 SCST 包，并且新的 ONTAP Mediator 版本不包含 SCST 包。
* 如果您计划使用 ONTAP Mediator 来监控多个 MetroCluster IP 配置，则支持取决于您的 Mediator 类型、ONTAP 版本和操作系统。有关详细信息，请参见link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["使用 ONTAP Mediator 监控多个 MetroCluster IP 配置"^]。
* 仅对以下用例支持安装支持 HTTPS 的 ONTAP Mediator：
+
** 您计划仅使用 ONTAP Mediator 来监控您的 SnapMirror 活动同步集群。
** 您计划使用 HTTPS 配置 ONTAP Mediator 以监视一个或多个 MetroCluster IP 配置。


* 在以下情况下，必须安装支持 iSCSI 和 HTTPS 的 ONTAP Mediator：
+
** 您计划使用 iSCSI 配置 ONTAP Mediator 以监视一个或多个 MetroCluster IP 配置。




* 当您针对现有的 ONTAP Mediator 安装运行安装程序时，它会检测到当前版本并提示您确认升级：
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* 作为升级的一部分，安装程序会收集升级前配置的支持包，并在升级 ONTAP Mediator 软件之前迁移数据库。
* 对于自动化用例，您可以使用 `./ontap-mediator-1.13.0/ontap-mediator-1.13.0 -y`命令跳过安装程序提示。


.步骤
. 在升级之前，如果您要升级到与以下版本之一配对的 ONTAP Mediator 实例上的 ONTAP Mediator 1.13 或更高版本，请完成以下子步骤：
+
** ONTAP 9.11.1 及更早版本
** 早于 9.12.1P15、9.13.1P12、9.14.1P8 和 9.15.1P2 的 ONTAP 补丁程序版本
+
... 将以下行添加到 `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml`文件中。
+
`'generate_unique_ca_name': false`

+
此文件在 ONTAP Mediator 升级过程中保留。





. 运行新版本的安装程序并根据需要响应提示：
+
[source, cli]
----
./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[NOTE]
====
要跳过升级期间的签名检查，请使用
`./ontap-mediator-1.13.0/ontap-mediator-1.13.0 --skip-code-signature-check`命令

====
+
安装程序检测到现有安装并提示您升级，然后安装所需的程序包并迁移配置。
