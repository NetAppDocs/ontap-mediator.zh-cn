= 更改 ONTAP Mediator 用户名和密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从安装了 ONTAP Mediator 的 Linux 主机更改 ONTAP Mediator 用户名或密码。



[[change-the-username]]
== 更改用户名

可以使用以下步骤更改用户名。

.关于此任务
在已安装 ONTAP Mediator 的 Linux 主机上执行此任务。

如果无法访问此命令，则可能需要使用完整路径运行该命令，如以下示例中所示：

`/usr/local/bin/mediator_username`

.步骤
通过选择以下选项之一更改用户名：

* *选项 (a)*：运行命令 `mediator_change_user`并响应提示，如下例所示：
+
....
 [root@mediator-host ~]# mediator_change_user
 Modify the Mediator API username by entering the following values:
     Mediator API User Name: mediatoradmin
                   Password:
 New Mediator API User Name: mediator
 The account username has been modified successfully.
 [root@mediator-host ~]#
....
* *选项（b）*：运行以下命令：
+
`MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD=mediator2 MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user`

+
[listing]
----
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD='mediator2' MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user
 The account username has been modified successfully.
 [root@mediator-host ~]#
----




[[change-the-password]]
== 更改密码

您可以使用以下步骤更改密码。

.关于此任务
在已安装 ONTAP Mediator 的 Linux 主机上执行此任务。

如果无法访问此命令，则可能需要使用完整路径运行该命令，如以下示例中所示：

`/usr/local/bin/mediator_change_password`

.步骤
通过选择以下选项之一更改密码：

* *选项（a）*：运行 `mediator_change_password`命令并响应提示，如以下示例所示：
+
....
 [root@mediator-host ~]# mediator_change_password
 Change the Mediator API password by entering the following values:
    Mediator API User Name: mediatoradmin
              Old Password:
              New Password:
          Confirm Password:
 The password has been updated successfully.
 [root@mediator-host ~]#
....
* *选项（b）*：运行以下命令：
+
`MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password`

+
示例显示密码从“mediator1”更改为“mediator2”。

+
....
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password
 The password has been updated successfully.
 [root@mediator-host ~]#
....
