= 准备安装 ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要安装 ONTAP Mediator，您需要满足所有先决条件，下载安装包，并在主机上运行安装程序。

[NOTE]
====
* 要将 ONTAP Mediator 升级到新版本，请参阅 link:../administer/upgrade-ontap-mediator-task.html["升级 ONTAP Mediator"]。
* 如果需要升级主机操作系统，并在此过程中重新安装或升级 ONTAP Mediator，请参阅link:../administer/upgrade-host-os-mediator-task.html["升级主机操作系统和 ONTAP Mediator"]。


====


[[installation-requirements]]
== 安装要求

安装 ONTAP Mediator 之前，请查看以下要求。

[NOTE]
====
* ONTAP Mediator 1.8 及更早版本与 Red Hat Enterprise Linux （RHEL） FIPS 模式不兼容，并会导致其无法成功安装。您可以使用  `fips-mode-setup --check` 命令检查是否启用了 FIPS 模式。您可以使用  `fips-mode-setup --disable` 命令禁用 FIPS 模式。禁用 FIPS 模式后重新启动，以成功安装 ONTAP Mediator 1.8 或更早版本。
* 如果安装失败，您可能需要尝试更新版本的 ONTAP Mediator。
* 从 2025 年 6 月 15 日起，您无法安装或升级 ONTAP Mediator 1.9 和 1.8，因为它们的代码签名证书已过期。如果安装失败，请改用 ONTAP Mediator 1.9.1 补丁版本。


====
* 如果安装  `yum-utils` 软件包，您可以使用  `needs-restarting` 命令。
* 从 ONTAP Mediator 1.11 开始，MetroCluster IP 配置支持 IPv6。




[[https-and-iscsi-installation-options-for-ontap-mediator]]
[[https-iscsi-installation]]
=== 适用于 ONTAP Mediator 的 HTTPS 和 iSCSI 安装选项

在安装 ONTAP Mediator 之前，请查看以下信息：

* 在 ONTAP Mediator 中，SCST 包用于为 MetroCluster IP 配置中的通信提供 iSCSI。SCST 包是在安装过程中编译的内核模块。从 ONTAP 9.19.1 和 Mediator 1.12 开始，您可以配置使用 HTTPS 而不是 iSCSI 监控 MetroCluster IP 配置的 ONTAP Mediator。
* 从 ONTAP 9.19.1 和 ONTAP Mediator 1.12 开始，您可以选择安装支持 iSCSI 和 HTTPS 的 ONTAP Mediator，或仅支持 HTTPS。如果您选择安装仅支持 HTTPS 的 ONTAP Mediator，则不会安装 SCST 软件包。
* 如果您从安装了 SCST 的 ONTAP Mediator 1.11 或更早版本升级，并且在升级期间选择了 HTTPS only 选项，则会卸载 SCST 包，并且新的 ONTAP Mediator 版本不包含 SCST 包。
* 如果您计划使用 ONTAP Mediator 来监控多个 MetroCluster IP 配置，则支持取决于您的 Mediator 类型、ONTAP 版本和操作系统。有关详细信息，请参见link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["使用 ONTAP Mediator 监控多个 MetroCluster IP 配置"^]。
* 仅对以下用例支持安装支持 HTTPS 的 ONTAP Mediator：
+
** 您计划仅使用 ONTAP Mediator 来监控您的 SnapMirror 活动同步集群。
** 您计划使用 HTTPS 配置 ONTAP Mediator 以监视一个或多个 MetroCluster IP 配置。


* 在以下情况下，必须安装支持 iSCSI 和 HTTPS 的 ONTAP Mediator：
+
** 您计划使用 iSCSI 配置 ONTAP Mediator 以监视一个或多个 MetroCluster IP 配置。






[[host-requirements]]
== 主机要求

在安装 RHEL 或 Rocky Linux 并配置关联的存储库时，请遵循这些要求。

[NOTE]
====
如果修改安装或配置过程，则可能需要执行其他步骤。

====
.Linux 发行版要求
* 根据 Red Hat 的最佳实践安装 RHEL 或 Rocky Linux。由于 CentOS 8.x 已结束生命周期，因此不建议使用 CentOS 8.x 的兼容版本。
* 在安装 ONTAP Mediator 时，确保系统可以访问所需的存储库，以便安装程序可以检索并安装所有必需的软件依赖项。
* 要使 yum 安装程序能够在 RHEL 存储库中查找依赖软件，请在安装期间或之后使用有效的 Red Hat 订阅注册系统。
+
[NOTE]
====
有关详细信息，请参见 Red Hat Subscription Manager 文档。

====




[[firewall-and-networking-requirements]]
== 防火墙和网络要求

ONTAP Mediator 使用多个端口与特定服务进行通信。

* 如果您使用的是第三方防火墙：
+
** 必须启用 HTTPS 访问。
** 必须将其配置为允许在端口 31784 和 3260 上进行访问。
+
使用默认的 Red Hat 或 CentOS 防火墙时，会在 Mediator 安装过程中自动配置防火墙。



* 对于无法访问互联网的 Linux 主机，请确保在本地存储库中提供所需的软件包。
+
如果在 Linux 环境中使用链路聚合控制协议（LACP），请配置内核并将 `sysctl net.ipv4.conf.all.arp_ignore`设置为 `2`。

[[install-ontap-mediator-when-uefi-secure-boot-is-enabled]]
== 启用 UEFI 安全启动时安装 ONTAP Mediator

ONTAP Mediator 可以安装在启用或未启用 UEFI 安全启动的系统上。

.关于此任务
* 如果不需要，或者正在排除 ONTAP Mediator 安装问题，您可以选择在安装 ONTAP Mediator 之前禁用 UEFI 安全启动。从您的计算机设置中禁用 UEFI 安全启动选项。
* 如果您安装了仅支持 HTTPS 的 ONTAP Mediator 1.12 或更高版本，则未安装 SCST 包，您可以跳过此任务。


[NOTE]
====
有关禁用 UEFI 安全启动的详细说明，请参见主机操作系统的文档。

====
要安装启用了 UEFI 安全启动的 ONTAP Mediator，您必须先注册安全密钥，然后才能启动服务。密钥在 SCST 安装的编译步骤中生成，并保存为机器上的私钥和公钥对。使用 `mokutil` 实用程序将公钥作为机器所有者密钥（MOK）添加到您的 UEFI 固件中，使系统能够信任并加载已签名的模块。将 `mokutil` 密码短语保存在安全的位置，因为在重新启动系统以激活 MOK 时需要使用它。

.步骤
. [[step_1_uefi]]检查您的系统是否已启用 UEFI 安全启动：
+
[source, cli]
----
mokutil --sb-state
----
+
结果表明此系统是否启用了 UEFI 安全引导。

+

 a| 




 a| 
UEFI 安全启动已禁用
 a| 
link:enable-access-repos-task.html["为 ONTAP Mediator 安装提供存储库访问权限"]

|===
+
[NOTE]
====
** 系统会提示您创建一个必须存储在安全位置的密码短语。您需要此密码短语才能在 UEFI 引导管理器中启用密钥。
** ONTAP Mediator 1.2.0 及更早版本不支持此模式。


====
