= 为 ONTAP Mediator 安装提供存储库访问权限
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您应该启用对存储库的访问权限，以便 ONTAP Mediator 可以在安装过程中访问所需的软件包。

.步骤
. 确定必须访问的存储库，如下表所示：
+
[cols="35,65"]
|===


| 如果您的操作系统是…… | 您必须提供对这些存储库的访问权限…… 


 a| 
Oracle Linux 10.x
 a| 
** ol-10-for-x86_64-baseos-rpms
** ol-10-for-x86_64-appstream-rpms




 a| 
Oracle Linux 9.x
 a| 
** ol-9-for-x86_64-baseos-rpms
** ol-9-for-x86_64-appstream-rpms




 a| 
RHEL 10.x
 a| 
** rhel-10-for-x86_64-baseos-rpms
** rhel-10-for-x86_64-appstream-rpms




 a| 
RHEL 9.x
 a| 
** rhel-9-for-x86_64-baseos-rpms
** rhel-9-for-x86_64-appstream-rpms




 a| 
RHEL 8.x
 a| 
** rhel-8-for-x86_64-baseos-rpms
** rhel-8-for-x86_64-appstream-rpms




 a| 
RHEL 7.x
 a| 
** rhel-7-server-optional-rpms




 a| 
CentOS 7.x
 a| 
** C7.6.1810 - 基本存储库




 a| 
Rocky Linux 10
 a| 
** appstream
** baseos




 a| 
Rocky Linux 9
 a| 
** appstream
** baseos




 a| 
Rocky Linux 8
 a| 
** appstream
** baseos


|===
. 使用以下过程之一启用对上面列出的存储库的访问，以便 ONTAP Mediator 可以在安装过程中访问所需的软件包。
+

NOTE: 如果 ONTAP Mediator 依赖于“额外”和“可选”存储库中的 Python 模块，则可能需要访问 `rhel-X-for-x86_64-extras-rpms`和 `rhel-X-for-x86_64-optional-rpms`文件。

+
.Oracle Linux 10.x 操作系统的程序
[%collapsible]
====
如果您的操作系统是 *Oracle Linux 10.x*，请使用此过程启用对存储库的访问：

.步骤
.. 订阅所需的存储库：
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
----
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
----
+
以下示例显示了此命令的执行情况：

+
[listing]
----
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
Repository 'ol-10-for-x86_64-baseos-rpms' is enabled for this system.
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
Repository 'ol-10-for-x86_64-appstream-rpms' is enabled for this system.
----
.. 运行以下命令来列出已启用的存储库：
+
[source, cli]
----
yum repolist
----
+
新订阅的存储库应显示在列表中。

.CentOS 7.x 操作系统的步骤
[%collapsible]
====
如果您的操作系统是 *CentOS 7.x*，请使用此过程启用对存储库的访问：


NOTE: 以下示例显示了 CentOS 7.6 的存储库，可能不适用于其他 CentOS 版本。请为您的 CentOS 版本使用基础存储库。

.步骤
.. 添加 C7.6.1810 - Base 存储库。C7.6.1810 - Base vault 存储库包含 ONTAP Mediator 所需的“kernel-devel”软件包。
.. 将以下行添加到 /etc/yum.repos.d/CentOS-Vault.repo。
+
[source, cli]
----
[C7.6.1810-base]
name=CentOS-7.6.1810 - Base
baseurl=http://vault.centos.org/7.6.1810/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
----
.. 运行以下命令来列出已启用的存储库：


[source, cli]
----
yum repolist
----
以下示例显示了此命令的执行情况。CentOS-7.6.1810 - Base 存储库应显示在列表中。

.Rocky Linux 10、9 或 8 操作系统的步骤
[%collapsible]
====
如果您的操作系统是 *Rocky Linux 10*、*Rocky Linux 9* 或 *Rocky Linux 8*，请使用此过程启用对存储库的访问：

.步骤
.. 订阅所需的存储库：
+
[source, cli]
----
dnf config-manager --set-enabled baseos
----
+
[source, cli]
----
dnf config-manager --set-enabled appstream
----
.. 执行 `clean`操作：
+
[source, cli]
----
dnf clean all
----
.. 验证存储库列表：
+
[source, cli]
----
dnf repolist
----


....

[root@localhost ~]# dnf config-manager --set-enabled appstream
