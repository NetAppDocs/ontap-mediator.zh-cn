= ONTAP Mediator 快速入门
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
要开始使用 ONTAP Mediator，请安装该软件并将其配置为与您的 ONTAP 环境配合使用。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"] 安装 ONTAP Mediator
[role="quick-margin-para"]
link:install/workflow-summary.html["安装 ONTAP Mediator"] 在您的系统上，并确保满足所有必需的依赖项。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"] 验证 ONTAP Mediator 安装
[role="quick-margin-para"]
link:install/verify-install-task.html["确认 ONTAP Mediator 安装成功"]通过查看服务状态并检查日志中是否有任何错误或警告。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"] 为您的 ONTAP 环境配置 ONTAP 调解器
[role="quick-margin-para"]
