= 了解 ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
ONTAP Mediator 支持 ONTAP 功能，为高可用性（HA）元数据提供持久且隔离的存储，提供同步节点运行状况查询功能以帮助确定仲裁，并充当控制器存活状态的 ping 代理。


NOTE: 本文档指的是本地版本的 ONTAP Mediator。有关从 ONTAP 9.17.1 开始提供的 ONTAP Cloud Mediator 的信息，请参见 link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html["SnapMirror 活动同步文档"^]。



[[how-ontap-mediator-works]]
== ONTAP Mediator 的工作原理

ONTAP Mediator 在第三故障域中的 Linux 主机上运行，与您的 ONTAP 集群分开，为 HA 元数据提供持久的隔离存储。ONTAP 使用此存储以及 Mediator 的节点运行状况查询和 ping 代理功能来监控 SnapMirror 活动同步关系和 MetroCluster IP 配置。

* ONTAP Mediator 使用节点管理 LIF 和集群管理 LIF 通过多个冗余路径与每个集群进行通信。这使得 ONTAP 能够区分整个站点故障和单个 InterSwitch 链路（ISL）故障。
* 在 SnapMirror 活动同步中，如果集群失去与其对等节点和 ONTAP Mediator 的连接，ONTAP 会将该对等节点视为无法访问，并可以自动故障转移到幸存的副本。
* 在 MetroCluster IP 配置中，ONTAP 调解器通过存储有关 MetroCluster 节点的状态信息并帮助确定故障期间的适当操作过程来协助调解器辅助的自动计划外切换（MAUSO）。




[[ontap-mediator-services]]
== ONTAP 调解器服务

ONTAP Mediator 提供两项额外的 systemctl 服务：

* *`ontap_mediator.service`*
+
维护 REST API 服务器以管理 ONTAP 关系。

* *`mediator-scst.service`*
+
控制 iSCSI 模块（SCST）的启动和关闭。





[[tools-provided-for-the-system-administrator]]
== 为系统管理员提供的工具

为系统管理员提供的工具：

* *`/usr/local/bin/mediator_change_password`*
+
提供当前 API 用户名和密码时设置新 API 密码。

* *`/usr/local/bin/mediator_change_user`*
+
提供当前 API 用户名和密码时设置新的 API 用户名。

* *`/usr/local/bin/mediator_generate_support_bundle`*
+
生成一个本地 tgz 文件，其中包含与 NetApp 客户支持进行通信所需的所有有用的支持信息。这包括应用程序配置、日志和一些系统信息。捆绑包在本地磁盘上生成，可以根据需要手动传输。存储位置：/opt/netapp/data/support_bundles/

* *`/usr/local/bin/uninstall_ontap_mediator`*
+
删除 ONTAP Mediator 包和 SCST 内核模块。这包括所有配置、日志和邮箱数据。

* *`/usr/local/bin/mediator_unlock_user`*
+
如果达到身份验证重试限制，则解除对 API 用户帐户的锁定。此功能用于防止暴力破解密码。它会提示用户输入正确的用户名和密码。

* *`/usr/local/bin/mediator_add_user`*
+
（仅限支持人员）用于在安装时添加 API 用户。





[[scst-and-kernel-updates]]
== SCST 和内核更新

ONTAP Mediator 使用 SCST 为 MetroCluster IP 配置中的通信提供 iSCSI。SCST 包是在安装过程中编译的内核模块。更新内核后，可能需要重新安装 SCST。或者，卸载 ONTAP Mediator，然后重新安装并重新配置 ONTAP 关系。请参阅 link:https://scst.sourceforge.net/["SCST：适用于 Linux 的通用 SCSI 目标子系统"^] 以了解有关 SCST 的更多信息。


NOTE: 您应该在 ONTAP 维护窗口中协调对服务器操作系统内核的任何更新。



[[support-for-https-and-iscsi]]
== 支持 HTTPS 和 iSCSI

从 ONTAP 9.19.1 和 ONTAP Mediator 1.12 开始，您可以配置使用 HTTPS 或 iSCSI 监控 MetroCluster IP 配置的 ONTAP Mediator。您可以选择安装支持 iSCSI 和 HTTPS 或仅支持 HTTPS 的 ONTAP Mediator。如果安装 ONTAP Mediator 时仅支持 HTTPS，则不会安装 SCST 软件包。有关详细信息，请参见link:install/prepare-install.html#https-iscsi-installation["适用于 ONTAP Mediator 的 HTTPS 和 iSCSI 安装选项"]。
