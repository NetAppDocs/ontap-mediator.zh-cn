* “是”表示建议将该操作系统用于 ONTAP Mediator 安装，并且完全兼容且受支持。
* “否”表示操作系统和 ONTAP Mediator 不兼容。
* “兼容”意味着 Red Hat 不再支持这些 RHEL 版本，但仍可以在其上安装 ONTAP Mediator。
* ONTAP Mediator 1.6 增加了对 Rocky Linux 9 和 8 的支持。
* ONTAP Mediator 1.5 是 RHEL 7.x 分支操作系统的最后一个受支持版本。
* Centos 8 因其重新分支而从所有版本中被移除。Centos Stream 被认为不是合适的生产目标操作系统。没有计划提供支持。
