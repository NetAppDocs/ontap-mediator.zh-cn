= ONTAP Mediator 中的新增功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator 的每个版本都提供了新的增强功能。


NOTE: 有关操作系统和 SCST 版本信息，请参见 link:support-matrix.html["支持矩阵"]。

[cols="25,75"]
|===


| ONTAP Mediator 版本 | 增强功能 


 a| 
1.12.1
 a| 
* 支持 RHEL：
+
** 兼容：10.1 和 9.7。
** 推荐：10.2、10.0、9.8、9.6、9.4 和 8.10。


* 支持 Rocky Linux 10.2、9.8 和 8.10。
* 支持使用 rhck 和 uek 内核的 Oracle Linux 10.1 和 9.8。
* 从 ONTAP Mediator 1.12.1 和 ONTAP 9.19.1 开始，配置了 HTTPS 的单个 ONTAP Mediator 实例可以同时监控以下配置：
+
** 如果安装在具有 8 核 CPU 和至少 16GB RAM 的主机上，则最多可安装 10 个四节点或 5 个八节点 MetroCluster IP 配置。请参阅 link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["使用 ONTAP Mediator 监控多个 MetroCluster IP 配置"^]。
** 如果安装在具有双核 CPU 的主机上，则为 1 个四节点 MetroCluster IP 配置和 1 个 SnapMirror 活动同步对等关系。请参阅 link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html#ontap-mediator["配置 ONTAP 调解器以进行 SnapMirror 活动同步"^]。


* 包括用于修复损坏的 SCST 安装的新工具。安装 ONTAP Mediator 后，您可以在 `/usr/local/bin/mediator_repair_scst`找到该工具。如果升级后的操作系统需要默认 SCST 软件包中未提供的 SCST 修补程序，则可以在操作系统升级后使用该工具。




 a| 
1.12
 a| 
* 支持 RHEL：
+
** 兼容：10.1 和 9.7。
** 推荐：10.2、10.0、9.8、9.6、9.4 和 8.10。


* 支持 Rocky Linux 10.2、9.8 和 8.10。
* 支持使用 rhck 和 uek 内核的 Oracle Linux 10.1 和 9.7。
* 从 ONTAP 9.19.1 和 ONTAP Mediator 1.12 开始，您可以在 MetroCluster IP 配置中配置使用 HTTPS 进行通信的 ONTAP Mediator。HTTPS 通过使用 SSL/TLS 加密整个会话来提高安全性。您可以选择安装仅支持 HTTPS 的 ONTAP Mediator。如果使用此安装方法，则不会安装 SCST 软件包。link:../install/prepare-install.html#https-iscsi-installation["详细了解 ONTAP Mediator 的 HTTPS 和 iSCSI 安装选项"]。




 a| 
1.11
 a| 
* 支持 RHEL 10.1、10.0、9.7、9.6、9.4 和 8.10。
* 支持 Rocky Linux 10.1、9.7 和 8.10。
* 支持使用 rhck 和 uek 内核的 Oracle Linux 10.0 和 9.6。
* 为 MetroCluster IP 配置添加对 IPv6 的支持。
* 增加了对 fapolicyd 的支持。




 a| 
1.10
 a| 
* 支持 RHEL 10.0、9.6、9.4 和 8.10。
* 支持 Rocky Linux 10.0、9.6 和 8.10。
* 将基础 Python 版本从 Python 3.9 升级到 Python 3.12。




 a| 
1.9.1
 a| 
* 支持 RHEL：
+
** 兼容：9.3、9.1、8.9、8.7、8.6、8.5 和 8.4。
** 推荐：9.5、9.4、9.2、9.0、8.10 和 8.8。


* 支持 Rocky Linux 9.5 和 8.10。
* 添加用于代码签名验证的新证书。
* 添加了对使用 `-skip-code-signature-check`标志跳过代码签名检查的支持。
* 当安装程序检测到过期的代码签名证书时，会显示警告。

+
